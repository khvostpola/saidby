# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The Covenant is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

In short: be respectful, assume good faith, accept constructive criticism, and do not
harass anyone. Maintainers may remove comments, commits or contributors that break these
rules.

Report unacceptable behavior to dev@estivenvalencia.co. Reports are handled privately.
