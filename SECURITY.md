# Security policy

Only the latest 0.x release receives fixes.

Report vulnerabilities through GitHub's private vulnerability reporting on this repository
(Security tab, "Report a vulnerability"), not in public issues. You will get an answer within
7 days and a coordinated disclosure window of up to 90 days.

Scope: saidby's own code. Model weights and third-party libraries are covered by their own
projects. saidby is designed so that processing never opens outbound connections; a report
showing otherwise is a vulnerability.
